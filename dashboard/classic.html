Live dashboard for the JAGA master node, served by nginx with a Python/SQLite service in between (server/); the trend table is a least-squares fit from server/trend.py. Data comes from GET /api/status, /api/nodes, /api/latest and /api/history?node=1-3 (see master/main/api.c), polled every 10s. Water level is SONAR_MOUNT_HEIGHT_MM − vertical distance per node_config.h; the warning/danger lines (700mm / 900mm) are placeholder thresholds — the firmware defines no alarm levels. Node positions are saved on the server (drag a pin, or Settings); the master's NODE_META values are only defaults. River lines are OpenStreetMap data (© OpenStreetMap contributors, ODbL). Open this page from file:// or plain http://: an HTTPS host blocks requests to the master's plain-HTTP API (mixed content). If .local doesn't resolve, use the IP the master logs on its serial console ("Got IP").
